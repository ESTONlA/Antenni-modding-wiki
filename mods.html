Installing mods

Give every mod its own folder.

LOCLM scans loclm/mods/. Each mod should contain its own DLL, metadata, assets, and dependencies.

Correct structure

The mod folder name and main DLL name should match.

loclm/mods/MyCoolMod/
+-- MyCoolMod.dll
+-- modinfo.json
+-- assets/
\-- dependency files...

Do not dump DLLs

Do not place every mod DLL directly inside mods/. LOCLM expects a folder per mod.

Disable safely

Move the mod to disabled_mods/, set enabled: false, or add a .disabled marker.

Reports

Loaded, failed, blocked, and conflict reports are written to loclm/Logs/.

Load order

Use metadata, not guesswork.

01

dependencies must exist or the mod is skipped.

02

loadAfter and loadBefore guide ordering.

03

priority is still used, but dependency rules matter more.
