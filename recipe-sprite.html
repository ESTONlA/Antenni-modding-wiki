Recipe

Recipe: add a new PNG sprite or replace an existing sprite texture.

The template supports PNG sprite helpers. Put PNG files under assets/sprites/, then call the helper from your C# load code.

Add a new sprite

File
assets/sprites/my_icon.png
C#
UndertaleSprite icon = context.AddSpriteFromPng(
    "spr_my_mod_icon",
    "sprites/my_icon.png",
    originX: 8,
    originY: 8);

The helper creates an embedded texture, texture page item, sprite resource, and adds the sprite to the default texture group when available.

Replace an existing sprite

C#
context.ReplaceSpriteTextureFromPng(
    "spr_existing_game_sprite",
    "sprites/replacement.png",
    frame: 0);
Replacement size matters.

The replacement is fitted into the existing texture page item. Use the same dimensions as the original frame unless you have tested the result carefully.

Beginner checklist

PNG format only.Use mod-prefixed sprite names.Check dimensions before replacing.Keep files under assets/sprites/.Ship the full output folder.Test on a clean cache.

Common errors

ErrorMeaning
Missing required asset fileYour path is wrong or the asset was not copied into output.
A sprite named ... already existsYou tried to add a new sprite using an existing resource name.
Unsupported texture sizeThe PNG dimensions are invalid for the helper.
Sprite does not have frameThe selected frame index does not exist.
