Assets

Assets live under the mod folder and are copied by the project file.

The template keeps non-C# files under assets/. The build copies those files into the output mod folder so LOCLM can read them at load time.

Asset folders

assets
assets/
+-- code/
|   \-- hooks/
+-- data/
|   \-- mod-config.json
+-- included/
+-- sounds/
\-- sprites/

How paths work

ModContext methods use paths relative to assets/. That means data/mod-config.json points at assets/data/mod-config.json.

C#
context.LoadJson<ModConfig>("data/mod-config.json", required: false);
context.LoadTextAsset("code/hooks/my_hook.gml");
context.LoadBinaryAsset("sprites/icon.png");

Good asset habits

Keep C# logic in C#.Keep large GML in assets/code/.Keep player config in assets/data/.Use lowercase folder names.Use clear file names.Fail early if a required asset is missing.
