Creating mods

C# DLL mods with GameMaker patch hooks.

The official template is CreatureProbe. It demonstrates metadata, config loading, GML patches, and a main menu tab.

Template

Build, copy, test.

Developers need the .NET SDK 10.0. Players only need the runtime.

Build command

dotnet build .\mod_template\CreatureProbe.csproj -c Release

Output

CreatureProbe/
+-- CreatureProbe.dll
+-- CreatureProbe.deps.json
+-- modinfo.json
+-- assets/
+-- UndertaleModLib.dll
\-- Underanalyzer.dll

Entry point

LOCLM searches for a public Load(int audiogroup, UndertaleData data) method.

Assets

Put GML files in assets/code/ and config/data files in assets/data/.

Test alone

Test your mod by itself before testing with other mods. Most conflicts are easier to find that way.
