Troubleshooting

Common issues, direct fixes.

Start with loclm/Logs/LOCLM_summary.txt. It contains warning counts, error counts, paths, hashes, and next steps.

Check that version.dll is beside LakeOfCreatures.exe. If LOCLM_proxy.log does not exist, the proxy DLL probably did not load.

Install .NET Desktop Runtime 10.0 x64, remove broken mods, and check LOCLM_summary.txt.

Each mod needs its own folder with a matching DLL and modinfo.json. Check failed_mods.json.

Open mod_conflicts.json, test mods one at a time, then adjust priority, loadAfter, or loadBefore.

Use the Windows x64 release, replace version.dll, and verify the game files in Steam.

Still stuck?

Zip loclm/Logs and share that folder.
