Template setup

Start from CreatureProbe, then rename it.

The official template gives you a working C# DLL mod with metadata, assets, config loading, and a sample main-menu tab.

Requirement

.NET SDK 10.0

Use the SDK for building mods. Players only need the runtime, but mod developers need the full SDK.

Source folder

mod_template/

The template source contains CreatureProbe.csproj, loclmMod.cs, ModContext.cs, assets, and included files.

Build command

Run this from the loader repository root.

dotnet build .\mod_template\CreatureProbe.csproj -c Release

Expected output

Copy the whole output folder into loclm/mods/. Do not copy only the DLL.

CreatureProbe/
+-- CreatureProbe.dll
+-- CreatureProbe.deps.json
+-- modinfo.json
+-- assets/
+-- GameSpecificData/
+-- UndertaleModLib.dll
\-- Underanalyzer.dll

Rename checklist

Change every identity, not just the DLL.

Project file: CreatureProbe.csproj Output folder in the project file Namespace in C# files Class name in loclmMod.cs DLL and mod folder name IncludedFiles/modinfo.json Text/config in assets/data/mod-config.json Button indexes and menu IDs if the mod adds UI
