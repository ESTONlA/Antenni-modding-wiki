Getting Started

Start from CreatureProbe, then rename it.

The official template gives you a working C# DLL mod with metadata, assets, config loading, and a sample main-menu tab.

Requirements

Requirement

.NET SDK 10.0

Use the SDK for building mods. Players only need the runtime, but mod developers need the full SDK.

Source folder

mod_template/

The template source contains CreatureProbe.csproj, loclmMod.cs, ModContext.cs, assets, and included files.

What the template contains

CreatureProbe is intentionally small, but it is a real working mod. It shows the folder layout, metadata, config loading, GML hooks, and the safe pattern for patching only audiogroup 0.

Template source
mod_template/
+-- CreatureProbe.csproj
+-- loclmMod.cs
+-- ModContext.cs
+-- ModConfig.cs
+-- IncludedFiles/
|   \-- modinfo.json
\-- assets/
    +-- code/
    |   \-- hooks/
    +-- data/
    |   \-- mod-config.json
    +-- included/
    +-- sounds/
    \-- sprites/

First edit pass

  1. Update metadata.Edit IncludedFiles/modinfo.json first so the loader shows the correct mod name, author, and compatibility data.
  2. Edit config defaults.Change values in assets/data/mod-config.json, including button label, menu title, body text, button index, and back button index.
  3. Move patch logic.Keep small setup in loclmMod.cs. Put larger GML into assets/code/ and load it with ModContext.
  4. Build Release.Use Release builds before testing installs or publishing a zip.

Build the template

Run this from the loader repository root.

PowerShell
dotnet build .\mod_template\CreatureProbe.csproj -c Release

Expected output

The project is configured to write directly into mod_template/CreatureProbe/. That output folder is the folder you copy into loclm/mods/.

CreatureProbe output
CreatureProbe/
+-- CreatureProbe.dll
+-- CreatureProbe.deps.json
+-- modinfo.json
+-- assets/
+-- GameSpecificData/
+-- UndertaleModLib.dll
\-- Underanalyzer.dll
Do not copy only the DLL.

Copy the whole output folder. The template also needs metadata, assets/config files, and dependency DLLs.

How the build copies files

CreatureProbe.csproj has custom copy steps so the final mod folder is ready to install.

Build behaviorResult
OutputPath is CreatureProbe\The compiled mod lands in a ready-to-copy folder.
assets/**/*.* is copiedGML hooks, config, sprites, sounds, and included files stay with the mod.
IncludedFiles/**/*.* is copiedmodinfo.json appears at the output folder root.
Duplicate asset roots are cleanedExtra accidental code/, data/, sprites/, sounds/, and included/ folders are removed from the output root.

Main entry point

LOCLM finds the public Load method and passes the current audiogroup plus the loaded game data. The template only patches audiogroup 0.

loclmMod.cs
public void Load(int audiogroup, UndertaleData data)
{
    if (audiogroup != 0)
    {
        return;
    }

    ModContext context = ModContext.Create(data);
    ModConfig config = context.LoadJson<ModConfig>("data/mod-config.json", required: false)
        ?? new ModConfig();

    InstallMainMenuTab(context, config);
}

Config keys used by CreatureProbe

The sample reads assets/data/mod-config.json into ModConfig.cs. Missing values fall back to the C# defaults.

KeyWhat it changes
verboseLoggingPrints extra template messages while loading.
enableMenuTabTurns the sample main-menu tab on or off.
mainMenuButtonLabelText shown on the added main-menu button.
mainMenuButtonIndexButton index used by the new menu button.
menuTabTitleTitle text drawn inside the sample tab.
menuTabBodyBody text drawn inside the sample tab.
backButtonIndexButton index used by the sample back button.
backButtonLabelText shown on the sample back button.

How the sample menu tab works

The sample adds a new button to the existing main menu, gives it text, maps it to a custom menu state, then draws and controls that state from main-menu hooks.

  1. Unlock a button slot.The template patches gml_GlobalScript_main_menu_spawn_buttons so the game knows the new button exists.
  2. Set button behavior.It patches gml_Object_obj_button_menu_Alarm_0 and gml_Object_obj_button_menu_Alarm_2 so the button has text and opens the sample tab.
  3. Draw the tab.obj_ctrl_main_menu_Draw_0.gml draws the title and body text.
  4. Handle input.obj_ctrl_main_menu_Step_0.gml and obj_ctrl_main_menu_Alarm_2.gml keep the tab interactive and allow leaving it.
Change indexes before adding more menu mods.

If two mods use the same button index or menu ID, they can conflict. Pick unique values and document them in your release notes.
