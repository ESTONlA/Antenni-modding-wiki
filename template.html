Getting Started

Start from CreatureProbe, then rename it.

The official template gives you a working C# DLL mod with metadata, assets, config loading, and a sample main-menu tab.

Requirements

Requirement

.NET SDK 10.0

Use the SDK for building mods. Players only need the runtime, but mod developers need the full SDK.

Source folder

mod_template/

The template source contains CreatureProbe.csproj, loclmMod.cs, ModContext.cs, assets, and included files.

Build the template

Run this from the loader repository root.

PowerShell
dotnet build .\mod_template\CreatureProbe.csproj -c Release

Expected output

The build output is the mod folder you copy into loclm/mods/.

CreatureProbe output
CreatureProbe/
+-- CreatureProbe.dll
+-- CreatureProbe.deps.json
+-- modinfo.json
+-- assets/
+-- GameSpecificData/
+-- UndertaleModLib.dll
\-- Underanalyzer.dll
Do not copy only the DLL.

Copy the whole output folder. The template also needs metadata, assets/config files, and dependency DLLs.

Rename checklist

Thing to renameWhy it matters
Project fileRename CreatureProbe.csproj so the project matches the mod.
Assembly nameThe output DLL should match the mod folder.
Root namespaceKeeps C# names clean and avoids template leftovers.
Main classRename the class in loclmMod.cs.
modinfo id/nameUpdate the player-facing mod name and author metadata.
Output folderThe folder should match the DLL name.
References to CreatureProbeSearch the project and replace remaining template names.
