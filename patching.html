Patching

Prefer small targeted patches over replacing whole scripts.

Most LOCLM mods patch GameMaker code entries. Smaller patches survive game updates better and conflict less with other mods.

Best

Append hooks

Add code at the end of an event or script when you only need to observe or add behavior.

Careful

Find and replace

Use exact small search strings. If the game updates and the string changes, the patch can fail.

Risky

Full replace

Replacing entire scripts is more likely to conflict with other mods and future game versions.

Find/replace example

This style is useful for small menu or variable patches.

context.FindReplaceCode(
    "gml_GlobalScript_main_menu_spawn_buttons",
    "btn_yy = 4;",
    "btn_yy = 4;\n    global.button_unlock[68] = 1;");

Append GML from a file

Keep bigger GML snippets in assets/code/, not inside C# strings.

context.AppendCodeFromFile(
    "hooks/obj_ctrl_main_menu_Draw_0.gml",
    "gml_Object_obj_ctrl_main_menu_Draw_0");

Conflict-safe habits

Make your patch easy to debug.

Use unique global variable names. Use unique button indexes and menu IDs. Log what your mod changes. Patch the smallest stable code snippet possible. Test with no other mods first. Document every game resource you touch.
