Patching

Patch text with exact replacements when possible.

Text patches are small and useful, but broad matching can hit the wrong string. Use the template's safe helpers to make failures obvious.

Available helpers

HelperUse
ReplaceTextOnceReplace one exact occurrence inside a larger string.
ReplaceTextExactReplace only when the entire source text matches.
ReplaceGameStringReplace an exact GameMaker string.
ReplaceGameStringContainsFind a GameMaker string by contained text and replace it.

Exact replacement example

C#
context.ReplaceGameString(
    "Old Text",
    "New Text");

Contains replacement example

C#
context.ReplaceGameStringContains(
    "Old",
    "New",
    expectedMatches: 1);
Set the expected match count.

If a future game update adds another matching string, the patch should fail loudly instead of replacing the wrong text.

Common mistakes

  • Replacing short words that appear in many places.
  • Changing text inside a script when a game string replacement would be safer.
  • Forgetting to escape quotes and backslashes in GML string literals.
  • Assuming capitalization and spacing will never change after a game update.
