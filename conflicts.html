Patching

Design patches as if another mod will touch the same file.

Conflicts are normal in GameMaker modding. Good mods minimize the surface area they patch and explain the resources they touch.

High-risk resources

Main menu scripts and button handlers.Global variables with generic names.Shared sprites and UI fonts.Audio resources used by many events.Room instance layers.Full script replacements.

Conflict-safe rules

  1. Patch the smallest stable snippet.Small patches are easier for LOCLM to track and easier for humans to review.
  2. Use unique names.Prefix globals, object names, sprite names, and function names with your mod ID.
  3. Declare relationships.Use dependencies, loadAfter, loadBefore, and incompatibleWith in modinfo.json.
  4. Read conflict reports.Check loclm/Logs/mod_conflicts.json when testing with other mods.

Common mistakes

  • Using globals like global.enabled instead of a unique mod-prefixed name.
  • Picking button indexes without checking the template defaults.
  • Shipping a full replacement script when an append hook would work.
  • Not telling users which mods are known incompatible.
