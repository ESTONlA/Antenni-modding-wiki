Installation

Drop LOCLM beside the game executable.

Install LOCLM into the folder that contains LakeOfCreatures.exe and data.win.

1

Open the game folder

In Steam, right-click Lake of Creatures, open Manage, then Browse local files.

2

Copy release files

Copy version.dll and the full loclm/ folder into the game folder.

3

Launch normally

Start the game through Steam. LOCLM prepares the cache and relaunches the game.

Expected layout

version.dll must be beside LakeOfCreatures.exe. Do not place it inside loclm/.

Lake of Creatures/
+-- LakeOfCreatures.exe
+-- data.win
+-- version.dll
\-- loclm/
    +-- loclm-csharp.exe
    +-- mods/
    +-- Logs/
    +-- disabled_mods/
    \-- quarantine/
Do not replace data.win.LOCLM creates LOCLM_CACHE_data.win and leaves the original untouched.

Requirements

What players need.

Runtime

Install .NET Desktop Runtime 10.0 x64 only if Windows asks for it. Players do not need the SDK.

Platform

LOCLM is built for Windows x64. Linux, Steam Deck, macOS, and native Proton setups are not officially supported right now.
