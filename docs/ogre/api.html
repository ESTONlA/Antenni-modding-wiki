API reference

Apply ModContext to Ogre resources

The helper API is shared with Lake. The resource names, GML bodies, room layers, sprite frames, and sound metadata are not.

Shared helper families

FamilyMethods
Logging and configLog, Warn, LoadJson<T>, asset path and file loaders.
RequirementsRequireObject, RequireSprite, RequireRoom, RequireCodeEntry, RequireFunction, RequireScript, RequireSound, RequireVariable.
CodeAppendCodeFromFile, HookCodeFromFile, HookFunctionFromFile, CreateFunctionFromFile, FindReplaceCode.
ObjectsCreateObject, NewObject, room placement, event replacement, and event creation.
MediaPNG sprite addition/replacement and sound addition/replacement.
Included filesAddIncludedFile, RequireIncludedFile, and game-path resolution.
Safe stringsReplaceTextOnce, ReplaceTextExact, ReplaceGameString, and ReplaceGameStringContains.

Typical Ogre entry point

public void Load(int audiogroup, UndertaleData data)
{
    if (audiogroup != 0)
    {
        return;
    }

    ModContext context = ModContext.Create(data);
    ModConfig config =
        context.LoadJson<ModConfig>("data/mod-config.json", false)
        ?? new ModConfig();

    InstallOgreFeature(context, config);
}

Guard game-specific setup

Your manifest is the first compatibility boundary. Resource requirements inside InstallOgreFeature are the second. Do not assume the loader's game detection proves your chosen target still has the expected body.

Use the source as the signature reference

This site groups the API by task. For exact overload arguments, open mod_template/ModContext.cs from the same Antenni release used to build the mod.

Keep the helper file with the project

That makes the mod's build behavior reproducible and avoids depending on undocumented methods from another template version.

Common mistakes

  • Using a verified method with an unverified Ogre resource name.
  • Assuming a room has a layer named Instances.
  • Replacing frame zero without checking sprite frame count and origin.
  • Adding a sound to the wrong audio group.
