Getting started

Install Antenni for Ogre Chambers 2222

Install the same Antenni runtime layout beside Ogre's supported executable, then verify the detected game profile in the logs.

Requirements

PlatformWindows x64
Runtime.NET 10 Desktop Runtime x64
Executableogre chambers 2.exe

Expected installation

Ogre Chambers 2222/
|-- ogre chambers 2.exe
|-- data.win
|-- version.dll
`-- antenni/
    |-- antenni-loader.exe
    |-- mods/
    |-- disabled_mods/
    |-- quarantine/
    `-- Logs/

Use Steam's Browse local files action rather than guessing the path. The proxy must be beside the exact executable recognized by Antenni.

First launch

  1. Copy all release filesInstall version.dll and the complete antenni/ folder.
  2. Start through SteamLaunch Ogre normally.
  3. Check the profileRead antenni/Logs/ANTENNI.log and confirm Ogre Chambers 2222 was detected.
  4. Check the cacheConfirm ANTENNI_CACHE_data.win is generated when active compatible mods require patching.
No in-game Antenni button is expected

The current Ogre profile has SupportsInGameMenu disabled. Core loading can work correctly without the Lake-specific menu.

Install an Ogre mod

Ogre Chambers 2222/
`-- antenni/
    `-- mods/
        `-- OgreExample/
            |-- OgreExample.dll
            |-- modinfo.json
            `-- assets/

The mod manifest must declare ogre-chambers-2222. A Lake-only mod should be skipped rather than patched into Ogre.
