Ogre / First mod
Tutorial

Build an Ogre-safe starter mod

Reuse the template infrastructure, not its Lake-specific behavior. Your first build should only prove that Ogre loads the DLL and manifest.

1. Copy the template source

Copy mod_template/, then rename the project, namespace, class, output folder, and manifest. Keep the library references and ModContext.cs.

2. Remove Lake menu code

Delete the call to InstallMainMenuTab and the complete method. Remove Lake hook files from assets/code/hooks/ unless you are replacing them with verified Ogre targets.

using UndertaleModLib;

namespace OgreExample;

public class OgreExample
{
    public void Load(int audiogroup, UndertaleData data)
    {
        if (audiogroup != 0)
        {
            return;
        }

        ModContext context = ModContext.Create(data);
        context.Log("OgreExample loaded for Ogre Chambers 2222.");
    }
}

3. Declare Ogre compatibility

{
  "name": "Ogre Example",
  "author": "Your Name",
  "description": "A minimal Ogre Chambers 2222 Antenni mod.",
  "supportedGames": ["ogre-chambers-2222"],
  "priority": 100
}

4. Build and verify

dotnet build .\OgreExample.csproj -c Release

Copy the complete output folder to Ogre Chambers 2222/antenni/mods/OgreExample/, launch the game, and confirm the log message and loaded status.

5. Discover before patching

Open Ogre's current data.win with a compatible inspection tool or use Antenni's generated resource reports. Select one exact resource and require it before changing anything.

UndertaleRoom room = context.RequireRoom("REPLACE_WITH_REAL_OGRE_ROOM");
context.Log($"Found Ogre room: {room.Name.Content}");
Placeholder names are intentionally invalid

This documentation does not invent Ogre resource names. Replace the placeholder only after inspecting the game build you are testing.

Common mistakes

  • Leaving supportedGames: ["lake-of-creatures"] in the copied manifest.
  • Leaving the CreatureProbe main-menu patch active.
  • Assuming similarly named GameMaker resources have identical code in both games.
  • Publishing a mod before testing a clean Ogre cache.
