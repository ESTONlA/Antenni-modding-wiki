Release notes that affect the wiki.

This page summarizes the loader changes that matter for installing mods, creating mods, debugging, and writing compatibility metadata.

v0.7.0-beta

Published May 18, 2026. This release focuses on future-proofing, safer menu injection, performance reporting, and mod compatibility metadata.

AreaWhat changed
Game updatesAdds supported_game_builds.json, unknown build warnings, game_resource_baseline.json, and game_compatibility_report.json.
Menu injectionLOCLM can continue building and launching the cache even if the in-game menu cannot be installed.
Runtime safetyInitializes safer defaults for LOCLM globals such as loaded mods, failed mods, conflicts, scroll state, and folder-copy timer.
PerformanceAdds cached file hashes, parallel package hashing/security scanning, performance_report.json, old-report compression, and a no-active-mod fast path.
Mod metadataAdds testedOn support so a mod can list the game builds it was tested against.
testedOn example
{
  "modName": "Example Mod",
  "authors": ["Example Author"],
  "description": "Example LOCLM mod.",
  "priority": 100,
  "testedOn": [
    "PUT_DATA_WIN_OR_EXE_HASH_PREFIX_HERE"
  ]
}
For modders

Use testedOn, keep patches small, prefer unique mod-prefixed globals, and check game_resource_baseline.json plus game_compatibility_report.json after game updates.

v0.6.0-beta

Published May 17, 2026. This release adds most of the current diagnostics, conflict reporting, and mod loading metadata.

AreaWhat changed
LogsMoves support files to loclm/Logs/ and adds LOCLM_summary.txt.
Startup checksDetects game updates, duplicate mod DLLs, missing dependency DLLs, SmartScreen markers, bad install layout, and unexpected executable launches.
Conflict detectionTracks shared edits to code, sprites, sounds, strings, objects, rooms, globals, menu button indexes, menu IDs, and resource names.
Mod loadingAdds enabled, loader version bounds, supportedGameVersions, dependency fields, incompatible mods, and load-before/load-after rules.
ReportsAdds mod_status.json, loaded_mods.json, failed_mods.json, blocked_mods.json, security_report.json, and mod_conflicts.json.

v0.5.0-beta

Published May 16, 2026. This release expands template helpers and adds security scanning and automatic cache invalidation.

  • Added real loader, proxy, and runtime logs.
  • Added security scanning, mod hash logging, security allowlists, and blocked-mod warnings.
  • Added automatic cache invalidation for loader, mod, config, removed-mod, and original game file changes.
  • Added AddSpriteFromPng, ReplaceSpriteTextureFromPng, AddSoundFromFile, ReplaceSoundFromFile, included-file helpers, and safe text replacement helpers.
  • Added assets/sprites/, assets/sounds/, and assets/included/ to the template.
