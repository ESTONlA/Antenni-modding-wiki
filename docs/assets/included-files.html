Assets

Ship runtime files under assets/included.

Included files are useful for data your GML needs at runtime. The template keeps them beside the mod, not injected into GameMaker's empty DAFL chunk.

Folder layout

Included assets
assets/
\-- included/
    +-- my_data.json
    \-- notes.txt

Register and use a file

C#
string gmlPath = context.GetIncludedFileGamePath("included/my_data.json");

Use the returned path when generated GML needs to reference the file.

Available helpers

MethodUse
AddIncludedFileAlias for requiring and registering an included file.
RequireIncludedFileFail if the included file is missing.
GetIncludedFileGamePathReturn the path that GML should use.

Common mistakes

  • Expecting included files to be injected into data.win.
  • Putting runtime files outside assets/included/.
  • Hardcoding absolute paths from your own PC.
  • Forgetting that players may install the game in a different Steam folder.
