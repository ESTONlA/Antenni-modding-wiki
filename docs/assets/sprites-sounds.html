Assets

Add or replace simple game assets from the template.

The current template includes helpers for PNG sprites and embedded WAV/OGG sounds. Keep the source files under assets/sprites/ and assets/sounds/.

Add a new sprite

C#
UndertaleSprite icon = context.AddSpriteFromPng(
    "spr_my_mod_icon",
    "sprites/probe_icon.png",
    originX: 8,
    originY: 8);

Replace a sprite texture

C#
context.ReplaceSpriteTextureFromPng(
    "spr_existing_game_sprite",
    "sprites/replacement.png");
Use the same size when replacing.

The helper fits the replacement into the existing texture page item. Matching the original sprite size avoids broken visuals.

Add or replace sounds

C#
UndertaleSound click = context.AddSoundFromFile(
    "snd_my_mod_click",
    "sounds/click.ogg");

context.ReplaceSoundFromFile(
    "snd_existing_game_sound",
    "sounds/replacement.wav");

Sound helpers currently target embedded .wav and .ogg files in the built-in audio group.

Common mistakes

  • Trying to load JPG or other image formats through PNG helpers.
  • Replacing a sprite with a different size and expecting it to fit automatically.
  • Using generic resource names like spr_icon instead of a mod-prefixed name.
  • Forgetting to ship the source asset inside the built assets/ folder.
