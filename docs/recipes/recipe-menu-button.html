Recipe

Recipe: add a main-menu button that opens your own tab.

This is the main thing CreatureProbe demonstrates. The button is created by patching existing menu setup code, then the tab is drawn by appended GML hooks.

What you will change

Button unlock state.Button instance creation.Button label.Button click behavior.Custom tab drawing.Back/leave behavior.

Step 1: pick indexes

The template uses button index 68 and back button index 69. For a real mod, pick values that are not used by your other mods.

ModConfig.cs
public int MainMenuButtonIndex { get; set; } = 68;
public int BackButtonIndex { get; set; } = 69;

Step 2: unlock and create the button

The sample patches gml_GlobalScript_main_menu_spawn_buttons. One patch unlocks the button slot. Another patch creates a new obj_button_menu instance and assigns its index.

C#
context.FindReplaceCode(
    "gml_GlobalScript_main_menu_spawn_buttons",
    "btn_yy = 4;",
    "btn_yy = 4;\n    global.button_unlock[68] = 1;");
This is game-version sensitive.

If the game update changes the searched text, the patch fails. That is better than silently placing a broken button.

Step 3: set label and click behavior

The sample patches obj_button_menu alarm code. One patch assigns the button text, another sets global.current_menu = 7 when the button is clicked.

Concept
case 68:
    my_text = "My Mod";
    fadeout_dir = 1;
    break;

case 68:
    global.current_menu = 7;
    break;

Step 4: draw your tab

Put the drawing code in assets/code/hooks/obj_ctrl_main_menu_Draw_0.gml and append it to gml_Object_obj_ctrl_main_menu_Draw_0.

C#
context.AppendCodeFromFile(
    "hooks/obj_ctrl_main_menu_Draw_0.gml",
    "gml_Object_obj_ctrl_main_menu_Draw_0",
    ("__MENU_TAB_TITLE__", QuoteGmlString(config.MenuTabTitle)),
    ("__MENU_TAB_BODY__", QuoteGmlString(config.MenuTabBody)));
