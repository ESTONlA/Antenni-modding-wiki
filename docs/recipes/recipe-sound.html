Recipe

Recipe: add or replace embedded WAV/OGG sounds.

The template supports embedded .wav and .ogg files in the built-in audio group. Keep sound files under assets/sounds/.

Add a new sound

File
assets/sounds/click.ogg
C#
UndertaleSound click = context.AddSoundFromFile(
    "snd_my_mod_click",
    "sounds/click.ogg");

The helper creates an embedded audio entry and a new UndertaleSound resource.

Replace an existing sound

C#
context.ReplaceSoundFromFile(
    "snd_existing_game_sound",
    "sounds/replacement.wav");
Only built-in embedded sounds are supported by this helper.

If the target sound is in another audio group, the helper throws instead of creating a broken replacement.

Format behavior

FormatBehavior
.wavStored as regular embedded audio.
.oggCan be stored compressed and optionally decompressed on load.
Other formatsRejected by the helper.

Common mistakes

  • Using MP3 or another unsupported format.
  • Replacing a sound from a non-built-in audio group.
  • Using a duplicate sound resource name.
  • Forgetting to include assets/sounds/ in the shipped output folder.
