Debugging

Write mods that do not look hostile.

LOCLM includes a basic security scan for mod DLLs. It is not a replacement for antivirus software, but it can block obviously risky behavior before a mod loads.

What LOCLM checks

  1. Finds the mod DLL.The loader inspects each mod folder.
  2. Calculates the hash.The hash is printed in the loader and written to reports.
  3. Scans for suspicious behavior.Risky APIs or patterns can block the mod.
  4. Writes reports.Security results go into loclm/Logs/.

Allowlist warning

A warning can be a false positive, but it is not always false.

Only allowlist a hash if you trust the mod author, understand what the mod is doing, and accept the risk.

security_allowlist.json
{
  "allowedModHashes": [
    "PUT_TRUSTED_MOD_SHA256_HASH_HERE"
  ]
}

Developer best practice

Do not download and execute external programs.Do not modify files outside the game/mod folder without clear consent.Keep source public when possible.Explain risky APIs in your README.Keep dependencies minimal.Never ask players to allowlist blindly.
