Mod basics

Keep code, config, and media organized

The template copies everything under assets/ into the built mod package while preserving subdirectories.

Recommended layout

assets/
|-- code/
|   `-- hooks/
|       `-- my_patch.gml
|-- data/
|   `-- mod-config.json
|-- included/
|   `-- defaults.json
|-- sounds/
|   `-- alert.wav
`-- sprites/
    `-- icon.png

Load typed config

public sealed class ModConfig
{
    public bool Enabled { get; set; } = true;
    public int PriceMultiplier { get; set; } = 2;
}

ModConfig config =
    context.LoadJson<ModConfig>("data/mod-config.json", required: false)
    ?? new ModConfig();

Paths passed to ModContext are relative to assets/. Optional config should have safe defaults so a missing user file does not crash the loader.

Store GML in files

Use AppendCodeFromFile, HookCodeFromFile, or CreateFunctionFromFile instead of embedding large GML strings in C#. This keeps syntax readable and makes token replacement explicit.

context.AppendCodeFromFile(
    "code/hooks/my_patch.gml",
    "gml_Object_obj_example_Step_0",
    ("__PRICE_MULTIPLIER__", config.PriceMultiplier.ToString()));

Sprites, sounds, and included files

context.AddSpriteFromPng(
    "spr_better_boat_icon",
    "sprites/icon.png");

context.ReplaceSoundFromFile(
    "snd_alert",
    "sounds/alert.wav");

string gamePath = context.AddIncludedFile(
    "included/defaults.json");

Use the exact overload required by your asset. Inspect ModContext.cs for origin, frame, audio-group, and format parameters rather than guessing them.

Assets are part of the release

A mod that works from the source tree can still fail for users if the release omits assets/. Test the exact folder you intend to publish.

Common mistakes

  • Passing assets/data/file.json instead of the relative path data/file.json.
  • Using Windows-only separators in GML or stored game paths.
  • Replacing a sprite frame that does not exist.
  • Shipping a sound format the target GameMaker data does not expect.
  • Forgetting to copy the assets in a custom project file.
