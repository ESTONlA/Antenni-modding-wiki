Modding Lake of Creatures With Mod Loader

Build C# mods that inspect and patch the GameMaker data, add resources, and extend the game without replacing the original data.win.

TemplateCreatureProbe

What is supported

Antenni 1.0.0 can load Lake mods, patch code and resources, generate a reusable cache, report conflicts, and install its Lake-specific in-game menu. The official CreatureProbe project is the recommended starting point.

The original game data stays untouched

Antenni writes ANTENNI_CACHE_data.win beside the original file and launches the game with that generated cache.

First mod path

  1. Install the loaderConfirm Antenni launches Lake and creates the antenni/Logs folder.
  2. Copy CreatureProbeRename the project, namespace, class, manifest, and output folder.
  3. Write a small patchStart with logging or one guarded code change before adding new resources.
  4. Build ReleaseCopy the complete output folder into antenni/mods/.
  5. Read the reportsUse mod_status.json, conflict reports, and the loader log to verify the result.

Important boundary

Game resources are not a stable public API. Names and code can change after a Lake update. Require every target you depend on, keep patches narrow, and test against a clean cache.
