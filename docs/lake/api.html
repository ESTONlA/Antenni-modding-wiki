ModContext helpers in the current template

This page documents helper families that exist in mod_template/ModContext.cs. Check the source for complete overload signatures.

Context and files

ModContext context = ModContext.Create(data);

context.Log("Patch started.");
context.Warn("Optional resource was not found.");

string path = context.GetAssetPath("data/mod-config.json");
string required = context.RequireAssetPath("sprites/icon.png");
string text = context.LoadTextAsset("code/hooks/example.gml");
byte[] bytes = context.LoadBinaryAsset("sounds/alert.wav");

Use LoadJson<T> for typed data. AssetRoot, CodeRoot, and DataRoot expose resolved source directories.

Resource requirements

context.RequireObject("obj_example");
context.RequireSprite("spr_example");
context.RequireRoom("rm_example");
context.RequireCodeEntry("gml_Object_obj_example_Step_0");
context.RequireFunction("example_function");
context.RequireScript("scr_example");
context.RequireSound("snd_example");
context.RequireVariable("example_variable");

These helpers return typed Undertale resources and throw a clear error when the named resource is missing.

Objects and rooms

UndertaleGameObject controller = context.CreateObject(
    "obj_betterboats_controller");

context.PlaceObjectInRoom(
    "rm_main",
    controller,
    "Instances");

The template also provides NewObject, AddObjectToRoom, and file-backed object event creation helpers.

GML code helpers

context.AppendCodeFromFile(relativePath, codeName);
context.HookCodeFromFile(relativePath, codeName);
context.HookFunctionFromFile(relativePath, functionName);
context.CreateFunctionFromFile(relativePath, functionName);
context.FindReplaceCode(codeName, search, replacement);
context.ReplaceObjectEventFromFile(relativePath, objectName, eventType);

ReplaceObjectEventFromFile and CreateObjectCodeFromFile have overloads for draw, key, mouse, other, step, and numeric event subtypes.

Sprites and sounds

UndertaleSprite sprite = context.AddSpriteFromPng(
    "spr_betterboats_icon",
    "sprites/icon.png");

context.ReplaceSpriteTextureFromPng(
    "spr_existing",
    "sprites/replacement.png",
    frame: 0);

UndertaleSound sound = context.AddSoundFromFile(
    "snd_betterboats_alert",
    "sounds/alert.wav",
    audioGroupId: 0);

context.ReplaceSoundFromFile(
    "snd_existing",
    "sounds/replacement.wav");
Confirm signatures in source

Sprite origin, frame, sound type, and audio group parameters have overload-specific details. Use editor completion or open ModContext.cs before copying an abbreviated example.

Included files

string gamePath = context.AddIncludedFile(
    "included/defaults.json");

string existing = context.RequireIncludedFile(
    "included/defaults.json");

string expectedPath = context.GetIncludedFileGamePath(
    "included/defaults.json");

Safe replacement helpers

string once = context.ReplaceTextOnce(
    source, search, replacement, "boat price patch");

string exact = context.ReplaceTextExact(
    source, search, replacement, expectedMatches: 2, "shop labels");

int changed = context.ReplaceGameString(
    "Old text", "New text", expectedMatches: 1);

int contains = context.ReplaceGameStringContains(
    "Old fragment", "New text", expectedMatches: 1);

Expected match counts turn an upstream game change into a controlled mod failure instead of an unnoticed partial patch.

Token replacement

ReplaceTokens and the replacement overload of AppendCodeFromFile substitute explicit tokens before compiling GML. Use uncommon tokens such as __BETTERBOATS_PRICE__.
