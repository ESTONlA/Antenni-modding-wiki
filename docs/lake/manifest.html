Lake / Manifest
Mod basics

Declare a Lake mod with modinfo.json

The manifest tells Antenni what the mod is, whether it is enabled, which game it supports, and how it should be ordered around other mods.

Recommended Lake manifest

{
  "modName": "Better Boats",
  "authors": ["Your Name"],
  "description": "Improves boat behavior in Lake of Creatures.",
  "enabled": true,
  "supportedGames": ["lake-of-creatures"],
  "priority": 100,
  "minLoaderVersion": "1.0.0",
  "maxLoaderVersion": "",
  "supportedGameVersions": [],
  "testedOn": [],
  "dependencies": [],
  "optionalDependencies": [],
  "incompatibleWith": [],
  "loadAfter": [],
  "loadBefore": []
}

Fields supported by the loader

FieldTypeMeaning
modNamestringHuman-readable mod name used in logs and reports.
authorsstring[]One or more author names.
descriptionstringShort explanation of the mod.
priorityintegerBase load ordering value. Lower values load earlier.
enabledbooleanSet false to skip the mod without deleting it.
minLoaderVersionstringOldest compatible Antenni version.
maxLoaderVersionstringNewest compatible Antenni version, or empty for no declared maximum.
supportedGamesstring[]Use lake-of-creatures for this manual.
supportedGameVersionsstring[]Accepted game version identifiers when your mod enforces them.
testedOnstring[]Build/hash identifiers the author tested.
dependenciesstring[]Mods that must load for this mod to work.
optionalDependenciesstring[]Integrations used when available.
incompatibleWithstring[]Mods that should not be loaded together.
loadAfterstring[]Ordering hints that place this mod after named mods.
loadBeforestring[]Ordering hints that place this mod before named mods.

Compatibility matters

Always declare supportedGames

Lake-specific GML patches can corrupt an Ogre cache. Use ["lake-of-creatures"] unless you have separately tested the same DLL against both games.

Load order is not conflict resolution

priority, loadAfter, and loadBefore decide sequence. They cannot make two incompatible full replacements safe. Check antenni/Logs/mod_conflicts.json and document required ordering for users.

Common mistakes

  • Invalid JSON caused by a trailing comma or missing quote.
  • Using a display name in one dependency field and a folder name in another without checking what the loader resolves.
  • Leaving supportedGames empty in a new cross-game ecosystem.
  • Using priority to hide a real resource conflict.
