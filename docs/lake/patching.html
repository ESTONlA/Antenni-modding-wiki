Lake / Patching
Patching

Patch Lake without replacing more than necessary

Treat each GameMaker resource as shared state. Require the target, make the smallest change that works, and fail clearly when the expected code changes.

Choose the least invasive operation

OperationUse it whenRisk
AppendCodeFromFileYour logic can safely run after an existing event.Low to medium; event ordering still matters.
HookCodeFromFileYou need the template hook mechanism for a code entry.Medium; understand the hook behavior first.
FindReplaceCodeYou need a precise edit inside decompiled GML.Medium to high; source text changes after updates.
ReplaceObjectEventFromFileYou intentionally own the whole event implementation.High; conflicts with every other full replacement.
CreateObject plus placementYour feature can be isolated in a new object.Often safer than editing a large shared controller.

Require targets before changing them

UndertaleGameObject menu =
    context.RequireObject("obj_ctrl_main_menu");

UndertaleCode draw =
    context.RequireCodeEntry("gml_Object_obj_ctrl_main_menu_Draw_0");

A failed requirement gives the loader and user a useful resource name. A null lookup followed by a random exception does not.

Use file-backed GML

// C#
context.AppendCodeFromFile(
    "code/hooks/obj_example_Step_0.gml",
    "gml_Object_obj_example_Step_0",
    ("__MOD_ENABLED__", config.Enabled ? "true" : "false"));
// assets/code/hooks/obj_example_Step_0.gml
if (__MOD_ENABLED__) {
    // Keep injected globals uniquely prefixed.
    global.betterboats_last_tick = current_time;
}

Make text replacement defensive

FindReplaceCode expects its search text to exist. Prefer a distinctive, short anchor rather than copying an entire function body. For ordinary strings and loaded text, use ReplaceTextOnce or ReplaceTextExact so match counts are verified.

Avoid shared-name conflicts

  • Prefix globals, scripts, objects, sprites, and sounds with a stable mod identifier.
  • Do not reuse CreatureProbe button index 68 in a published mod without checking other menu mods.
  • Do not replace the full main-menu event just to draw one label.
  • Read mod_conflicts.json after testing multiple mods.

Test after a game update

Delete or clear the generated cache, launch with only your mod, and inspect the compatibility and resource reports. If a target changed, update the patch rather than weakening checks until it happens to run.

Prefer an isolated object for a self-contained feature

A new object with its own events and uniquely prefixed resources usually creates fewer conflicts than repeated edits to a central controller.
