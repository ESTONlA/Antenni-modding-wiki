Debugging

Debug the loader, then the mod, then the patch

Separate startup failures from manifest skips, security blocks, C# load failures, and invalid GML patches.

Start with the logs folder

Lake of Creatures/
`-- antenni/
    `-- Logs/
        |-- ANTENNI.log
        |-- mod_status.json
        |-- loaded_mods.json
        |-- failed_mods.json
        |-- blocked_mods.json
        |-- mod_conflicts.json
        |-- security_report.json
        `-- game_compatibility_report.json

Available report names can vary by build and execution path. Send the complete Logs/ folder when asking for help.

No console or log

  • Confirm version.dll is beside LakeOfCreatures.exe.
  • Confirm both files are x64-compatible.
  • Check Windows file Properties for an Unblock option.
  • Confirm the complete antenni/ directory was installed.
  • Repair .NET 10 Desktop Runtime x64 and Microsoft Visual C++ x64 Runtime.

Mod is skipped

Check mod_status.json. Common causes are enabled: false, a .disabled marker, placement under disabled_mods/, missing dependencies, incompatible mods, loader version limits, or a supportedGames mismatch.

Mod is blocked

Read security_report.json. Security findings can be false positives, but are not automatically harmless. Review the source and behavior before adding any hash to security_allowlist.json.

Cache build fails

  • Test with only the failing mod installed.
  • Clear the generated cache and retry.
  • Read the exact missing resource or GML compile error.
  • Verify all GML tokens were replaced.
  • Check that a full event replacement did not remove required game logic.

Game starts but behavior is wrong

Inspect mod_conflicts.json, disable other mods, and compare the exact release folder with your development output. For menu problems, verify every Draw and Step patch is guarded by the intended menu state.

After a Lake update

Regenerate the cache, review game_compatibility_report.json, and confirm each required resource still exists. Unknown builds are warnings, not proof of failure, but every patch should be retested.

Make failures reproducible

Record the Antenni version, game build, mod list, exact mod packages, and the complete logs from the same failed run.
