Lake / Menu modding
Lake-specific

Add Lake menu features without owning the menu

CreatureProbe demonstrates a button and tab, but published mods must isolate their state and avoid indexes already used by Antenni or another mod.

How the sample works

  1. Unlock an indexThe template edits main_menu_spawn_buttons to enable button index 68.
  2. Create a buttonIt creates an obj_button_menu instance and assigns the index.
  3. Assign textIt adds a case to the menu button alarm that resolves the visible label.
  4. Change menu stateThe click handler selects a custom menu state.
  5. Draw and closeFile-backed Draw, Step, and Alarm patches render the tab and return to the main menu.

What you must rename

  • Button index and any back-button index.
  • Menu state ID.
  • Every global variable used by the panel.
  • Created object, script, sprite, and sound names.
  • Token names inside GML files.

Do not assume index 68 is free

The sample uses 68 because it is a demonstration. A release should coordinate indexes, detect conflicts where possible, and expose them in config only if users understand the compatibility impact.

Two menu mods can both load and still break the menu

Load order cannot fix duplicate button indexes, duplicate menu IDs, or two full replacements of the same event.

Prefer isolated drawing and input

Keep custom panel state under uniquely prefixed globals. Gate every Draw and Step block behind the exact menu state. A missing guard is why custom content can appear over Settings, New Game, or unrelated screens.

if (global.current_menu == my_mod_menu_id) {
    // Draw only this mod's panel.
}

Test matrix

  • Open and close the custom panel repeatedly.
  • Open every original menu after closing it.
  • Test keyboard, controller, and mouse input.
  • Test with Antenni's own in-game menu.
  • Test with another menu mod and inspect conflicts.
  • Regenerate the cache after changing injected GML.
