Getting started

Install Antenni for Lake

Put the proxy and loader directory beside the game executable, then launch Lake normally through Steam.

Requirements

PlatformWindows x64
Runtime.NET 10 Desktop Runtime x64
GameSteam installation

The Microsoft Visual C++ x64 runtime may also be required by the native proxy. Install official Microsoft runtimes rather than downloading individual DLL files from third-party sites.

Find the game directory

In Steam, open Lake of Creatures, select Manage, then Browse local files. The folder must contain both LakeOfCreatures.exe and data.win.

Expected installation
Lake of Creatures/
|-- LakeOfCreatures.exe
|-- data.win
|-- version.dll
`-- antenni/
    |-- antenni-loader.exe
    |-- mods/
    |-- disabled_mods/
    |-- quarantine/
    `-- Logs/

Install and launch

  1. Copy the proxyPlace version.dll beside LakeOfCreatures.exe.
  2. Copy the loaderPlace the complete antenni/ directory in the same game folder.
  3. Start through SteamUse the normal Play button. The proxy starts Antenni before the patched game launch.
  4. Check the resultConfirm antenni/Logs/ANTENNI.log exists and the Lake main menu has the Antenni button.

Generated files

Antenni creates ANTENNI_CACHE_data.win in the game directory. Logs and JSON reports are written under antenni/Logs/. Do not rename or replace the original data.win.

No loader log usually means the proxy never started

Verify the file is named exactly version.dll, is x64, is not blocked by Windows, and is beside the supported executable.

Install a mod

Lake of Creatures/
`-- antenni/
    `-- mods/
        `-- MyMod/
            |-- MyMod.dll
            |-- modinfo.json
            `-- assets/

The mod folder and primary DLL should use the same name. Copy the whole built mod folder, not only the DLL.
