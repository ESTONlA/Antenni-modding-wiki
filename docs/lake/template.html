Official starter

Start from CreatureProbe, then rename it.

The official template is a working .NET 10 C# DLL mod with metadata, asset copying, config loading, patch helpers, and a Lake main-menu example.

What each file does

PathPurpose
CreatureProbe.csprojTargets net10.0, references Undertale libraries, copies assets, and defines the output directory.
AntenniMod.csContains the public mod class and Load(int audiogroup, UndertaleData data) entry point.
ModContext.csProvides logging, resource requirements, GML patching, sprite, sound, included-file, and safe replacement helpers.
ModConfig.csDefines typed defaults for assets/data/mod-config.json.
IncludedFiles/modinfo.jsonDeclares metadata and Lake compatibility for the loader.
assets/code/hooks/Stores injected GML outside C# so patches are readable and maintainable.

Build the template

PowerShell from the repository root
dotnet build .\mod_template\CreatureProbe.csproj -c Release

Do not copy only the DLL

Copy the whole CreatureProbe/ output folder. The template uses metadata, dependencies, config, GML files, and game-specific analyzer data.

Template limitations

The sample menu patch uses Lake-specific code entries and button indexes. It is an example, not a universal menu API. Remove it if your mod does not need a menu, and never use it unchanged for Ogre Chambers 2222.
