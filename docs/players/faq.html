For Players

FAQ

Short answers for common LOCLM install, runtime, and support questions.

Is LOCLM official?

No. LOCLM is an unofficial community project.

Does LOCLM edit data.win?

No. LOCLM reads data.win, writes LOCLM_CACHE_data.win, and relaunches the game with that generated cache.

Do I need .NET?

If Windows asks for it, install .NET Desktop Runtime 10.0 x64. Players do not need the .NET SDK.

Does LOCLM support Linux or Steam Deck?

Not officially right now. LOCLM is built for the Windows version of Lake of Creatures and uses a Windows version.dll proxy.

Where do mods go?

Mods go in loclm/mods/. Each mod should have its own folder.

Can I disable a mod without deleting it?

Yes. Move it to loclm/disabled_mods/, set "enabled": false in modinfo.json, or create a .disabled marker file inside the mod folder.

What if the LOCLM menu does not appear?

Mods may still load even if menu injection fails. Check loclm/Logs/game_compatibility_report.json and LOCLM_summary.txt.

What should I send when reporting a bug?

Zip loclm/Logs/. Do not send your whole game folder.
