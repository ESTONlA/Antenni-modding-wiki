For Players

Each mod gets its own folder.

LOCLM loads mods from Lake of Creatures/loclm/mods/. Do not drop every DLL directly into the mods folder.

Correct layout

Installed mod
Lake of Creatures/
\-- loclm/
    \-- mods/
        \-- MyCoolMod/
            +-- MyCoolMod.dll
            +-- MyCoolMod.deps.json
            +-- modinfo.json
            +-- assets/
            \-- dependency files...
Folder and DLL names should match.

If the folder is MyCoolMod, the main DLL should be MyCoolMod.dll.

Install a mod

  1. Download the mod.Use trusted sources and read the mod author's install notes.
  2. Extract the archive.If it is a zip, extract it first.
  3. Copy the whole folder.Put the full mod folder inside loclm/mods/.
  4. Launch the game.LOCLM will scan the folder and rebuild the cache when needed.

Disable a mod

You can disable a mod without deleting it.

MethodUse
Move the folderMove the mod into loclm/disabled_mods/.
Manifest flagSet "enabled": false in modinfo.json.
Marker fileCreate a file named .disabled inside the mod folder.

Load order and conflicts

LOCLM uses priority, dependencies, optionalDependencies, loadAfter, and loadBefore from each mod's modinfo.json. Lower priority values load earlier unless dependency rules change the order.

Mods can conflict if they edit the same code, sprite, sound, object, room, button index, menu ID, or global variable. LOCLM writes possible conflicts to loclm/Logs/mod_conflicts.json and can show them in the in-game LOCLM menu.

Blocked mods

If LOCLM blocks a mod, check loclm/Logs/security_report.json, loclm/Logs/blocked_mods.json, and loclm/quarantine/. Security warnings can be false positives, but they are not always false.

Do not allowlist random DLLs.

Only allowlist a mod hash when you trust the mod author and understand why LOCLM flagged it.
