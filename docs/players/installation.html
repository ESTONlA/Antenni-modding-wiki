For Players

Install LOCLM beside the game executable.

LOCLM is installed into the Lake of Creatures game folder. The original data.win should stay untouched.

Before you start

Windows 10 or Windows 11.Steam version of Lake of Creatures.Latest LOCLM Windows x64 release.Permission to copy files into the game folder..NET Desktop Runtime 10.0 x64 if Windows asks for it.Microsoft Visual C++ Redistributable if Windows reports missing native runtime files.

Find the game folder

  1. Open Steam.Right-click Lake of Creatures.
  2. Browse local files.Choose Manage, then Browse local files.
  3. Check the files.The folder should contain LakeOfCreatures.exe and data.win.

Copy the loader files

Copy these into the same folder as LakeOfCreatures.exe:

Expected layout
Lake of Creatures/
+-- LakeOfCreatures.exe
+-- data.win
+-- version.dll
\-- loclm/
    +-- loclm-csharp.exe
    +-- loclm-csharp.dll
    +-- supported_game_builds.json
    +-- mods/
    +-- Logs/
    +-- disabled_mods/
    \-- quarantine/
Folder placement matters.

Do not put version.dll inside loclm/. Do not move loclm/ outside the game folder.

First launch

  1. Launch through Steam.Start the game normally.
  2. Let LOCLM build the cache.The loader reads data.win, scans mods, writes LOCLM_CACHE_data.win, then relaunches the game.
  3. Check logs if it fails.Support files are written to loclm/Logs/.

Update or uninstall

TaskSteps
Update LOCLMClose the game, replace version.dll and the loader files in loclm/, keep loclm/mods/, then launch again.
Uninstall LOCLMClose the game, delete version.dll, delete loclm/, and delete LOCLM_CACHE_data.win if it exists.
Do not delete data.win.

That is the original game data file. LOCLM uses a generated cache file instead.
