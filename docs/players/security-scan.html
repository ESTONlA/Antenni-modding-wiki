For Players

Security scanning is a safety layer, not antivirus.

LOCLM scans mod DLLs for suspicious behavior before loading them, logs the mod hash, and blocks mods that trip the scan.

What happens

  1. LOCLM finds the mod DLL.Each mod should be in its own folder.
  2. LOCLM calculates the hash.The hash identifies the exact file that was scanned.
  3. The security scan runs.Newer versions scan planned mods in parallel and skip very large files instead of reading them fully into memory.
  4. Suspicious mods are blocked.Blocked mod reports are written to loclm/Logs/, and marker files are written to loclm/quarantine/.

Allowlist

The allowlist is for trusted false positives. Only add hashes for mods you trust.

security_allowlist.json
{
  "allowedModHashes": [
    "PUT_TRUSTED_MOD_SHA256_HASH_HERE"
  ]
}
A warning can be real.

Do not allowlist a mod just because you want it to load. Ask the mod author to explain the warning if you are unsure.

Best practice

  • Download mods from trusted sources.
  • Do not run random DLL files from unknown people.
  • Keep mods in their own folders.
  • Remove blocked mods unless you know exactly why they were blocked.
  • Send security_report.json to the mod author when asking about a blocked mod.
