For Players

Send the Logs folder when asking for help.

LOCLM writes support files to Lake of Creatures/loclm/Logs/. These reports are safer and more useful than screenshots of random errors.

Main files

FilePurpose
LOCLM.logMain loader startup, mod scanning, mod loading, warnings, and errors.
LOCLM_proxy.logNative version.dll proxy startup. If missing, the proxy probably did not load.
LOCLM_runtime.logIn-game runtime log written by LOCLM GameMaker hooks.
LOCLM_summary.txtHuman-readable summary with versions, paths, hashes, warning/error counts, and next steps.

Mod reports

FilePurpose
mod_status.jsonPer-mod loading, compatibility, timing, and warning status.
loaded_mods.jsonMods that loaded successfully.
failed_mods.jsonMods that failed to load.
blocked_mods.jsonMods blocked by the security scan.
security_report.jsonSecurity scan details and hashes.
mod_conflicts.jsonPossible resource, global, menu index, and load-order conflicts.

Cache and game update reports

Recent LOCLM releases also write compatibility and performance reports.

FilePurpose
LOCLM_CACHE_manifest.jsonTracks cache fingerprints and injection version.
game_baseline.jsonTracks local game executable and data.win hashes.
game_resource_baseline.jsonRecords game resources used to detect changed injection targets.
game_compatibility_report.jsonExplains unknown builds and changed menu injection targets.
performance_report.jsonPhase timings, loader time, working set, and managed heap size.
file_hash_cache.jsonCached file hashes used to avoid unnecessary rehashing.

What to send

Zip loclm/Logs/.

Do not send the whole game folder. Do not send data.win unless a developer specifically asks and you are allowed to share it.
