For Players

Start with the Logs folder.

Most LOCLM problems can be diagnosed from loclm/Logs/LOCLM_summary.txt plus the mod status, security, and conflict reports.

First step

Open this folder:

Path
Lake of Creatures/loclm/Logs/

If you need help, zip the whole Logs folder. Do not send your whole game folder.

Game does not start

Check that the game folder contains LakeOfCreatures.exe, data.win, version.dll, and loclm/. Then check loclm/Logs/LOCLM_proxy.log.

  • If LOCLM_proxy.log is missing, version.dll probably did not load.
  • Put version.dll beside LakeOfCreatures.exe.
  • Make sure antivirus did not block or delete the DLL.
  • Install the Visual C++ Redistributable if Windows reports missing native runtime files.

Loader opens but game does not relaunch

  • Install .NET Desktop Runtime 10.0 x64 if Windows asks for it.
  • Remove broken mods from loclm/mods/.
  • Delete LOCLM_CACHE_data.win and launch again.
  • Make sure the game folder is writable.

Mods do not load

Check loclm/Logs/mod_status.json and loclm/Logs/failed_mods.json. Make sure every mod has its own folder with a matching DLL and modinfo.json.

Correct
loclm/mods/MyCoolMod/MyCoolMod.dll
loclm/mods/MyCoolMod/modinfo.json

Unknown game build

Newer LOCLM releases warn when the current game hash is not listed in supported_game_builds.json. This does not always mean the loader is broken, but a game update can break fragile patches.

Check loclm/Logs/game_compatibility_report.json and loclm/Logs/game_resource_baseline.json, then test mods one at a time.
