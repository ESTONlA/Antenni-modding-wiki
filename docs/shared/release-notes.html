Current release

Antenni Loader 1.0.0

The 1.0.0 release turns the former single-game loader into Antenni, a game-profile-based loader for Lake of Creatures and Ogre Chambers 2222.

Supported games

GameProfile IDExecutableStatus
Lake of Creatureslake-of-creaturesLakeOfCreatures.exeCore loading and in-game Antenni menu.
Ogre Chambers 2222ogre-chambers-2222ogre chambers 2.exeCore loading and patching; no in-game Antenni menu.

Runtime naming

  • Loader directory: antenni/
  • Managed loader: antenni-loader.exe
  • Generated cache: ANTENNI_CACHE_data.win
  • Main log: antenni/Logs/ANTENNI.log
  • Native proxy: version.dll

Game compatibility

Mods can declare supportedGames in modinfo.json. New mods should use the exact profile ID and keep game-specific patches separate.

For existing Lake mod authors

  1. Update namesReplace old loader folder and cache references in documentation and scripts.
  2. Declare LakeAdd "supportedGames": ["lake-of-creatures"].
  3. RebuildUse the Antenni 1.0.0 template and dependencies.
  4. RetestVerify cache generation, security scan, conflict reports, and menu behavior.
