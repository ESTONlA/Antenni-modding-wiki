Security

Security scanning and allowlisting

Antenni performs a basic static scan to catch obviously risky mod behavior before loading a DLL. It does not replace antivirus software or source review.

What happens

  1. HashAntenni calculates a deterministic hash for the mod package.
  2. ScanIt checks the DLL and selected files for suspicious API and string patterns.
  3. DecideRisky mods can be blocked unless the exact hash is trusted.
  4. ReportThe loader records findings, blocked status, and skipped oversized files.

Current rule categories

The source currently checks patterns related to external process spawning, native code and memory APIs, network access, destructive file operations, Windows registry access, and dynamic code loading.

A warning can be a false positive, but it is not always false

Do not allowlist a mod only because you want it to load. Review the source, author, purpose, and exact finding first.

Reports and blocked state

antenni/Logs/security_report.json
antenni/Logs/blocked_mods.json
antenni/quarantine/

The console also prints the mod hash during loading. Use the report from the same package you reviewed.

Allowlist file

// antenni/security_allowlist.json
{
  "allowedModHashes": [
    "PUT_REVIEWED_SHA256_HASH_HERE"
  ]
}

An allowlist entry trusts one exact hash. A changed mod should produce a different hash and must be reviewed again.

Player guidance

  • Download mods from known sources and authors.
  • Prefer mods with public source code.
  • Do not run random DLLs or scripts supplied outside the mod package.
  • Send the finding report to the author when behavior appears legitimate.
  • Remove a blocked mod when you cannot explain the flagged behavior.

Developer guidance

  • Avoid launching external programs.
  • Avoid network and registry access unless the feature clearly requires it.
  • Do not write outside the game/mod directory without explicit user consent.
  • Explain required risky APIs and keep source available for review.
  • Keep release contents minimal so users can understand what is executed.
