LOCLM Modding Manual

Documentation for creating LOCLM mods for Lake of Creatures. This manual focuses on C# DLL mods, the official template, GameMaker/GML patching, metadata, release packaging, and debugging.

What this wiki helps with

LOCLM mods are C# DLLs. When the game starts, LOCLM reads the original data.win, loads each mod, lets the mod patch GameMaker resources in memory, then writes a generated cache file for the game to run.

Scope

This site is for making mods. It does not focus on installing the loader as a player.
