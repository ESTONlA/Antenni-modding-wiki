What LOCLM does

LOCLM is a community-made mod loader for Lake of Creatures. It loads mods from a dedicated folder, reads the original data.win, applies mod patches in memory, writes LOCLM_CACHE_data.win, then launches the game against that generated cache. The original data.win is left untouched.

Runtime layout
Lake of Creatures/
+-- LakeOfCreatures.exe
+-- data.win
+-- version.dll
+-- LOCLM_CACHE_data.win
\-- loclm/
    +-- loclm-csharp.exe
    +-- supported_game_builds.json
    +-- mods/
    +-- disabled_mods/
    +-- quarantine/
    \-- Logs/
