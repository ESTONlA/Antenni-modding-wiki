Getting Started

LOCLM Modding Manual

A practical manual for building Lake of Creatures mods with LOCLM. Start from the official C# template, patch GameMaker resources safely, package a complete mod folder, and debug failures from loader reports.

What this wiki helps with

LOCLM mods are C# DLLs. When the game starts, LOCLM reads the original data.win, loads each mod, lets the mod patch GameMaker resources in memory, then writes a generated cache file for the game to run.

Scope

This site is for making mods. It does not focus on installing the loader as a player.

Create your first mod

Start from the template

Build the official CreatureProbe template so you have a working C# DLL mod structure.

Rename the mod

Rename the project, namespace, class, output folder, DLL, and metadata so your mod has its own identity.

Add patches

Use ModContext helpers to patch scripts, append GML hooks, load config, and locate game resources.

Package the output folder

Ship the complete mod folder, not only the DLL.
