Metadata

modinfo.json controls identity, compatibility, and load order.

Every LOCLM mod should include modinfo.json in the root of the mod folder.

Recommended example

Use dependencies and explicit load rules when your mod expects another mod to run first.

{
  "modName": "Example Mod",
  "authors": ["Example Author"],
  "description": "Example LOCLM mod.",
  "priority": 100,
  "enabled": true,
  "minLoaderVersion": "0.6.0-beta",
  "maxLoaderVersion": "",
  "supportedGameVersions": ["*"],
  "dependencies": [],
  "optionalDependencies": [],
  "incompatibleWith": [],
  "loadAfter": [],
  "loadBefore": []
}
FieldUse
modNameDisplay name. Required and should be short.
authorsAt least one author name. Required.
priorityBase load order. Lower values load earlier unless dependencies change order.
enabledSet false to disable the mod without deleting files.
dependenciesRequired mods. Missing dependencies skip the mod.
optionalDependenciesSoft integrations. The mod can still load without them.
incompatibleWithKnown-bad mod combinations.
loadAfterLoad after another mod if it exists.
loadBeforeAsk LOCLM to load this mod before another mod.
supportedGameVersionsUse *, any, or hash prefixes for game build checks.
