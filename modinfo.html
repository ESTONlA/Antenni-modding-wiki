modinfo.json

Compatibility and load order in one file.

Every mod should include modinfo.json in the mod root folder.

Recommended example

Use dependencies and load rules when mods rely on each other.

{
  "modName": "Example Mod",
  "authors": ["Example Author"],
  "description": "Example LOCLM mod.",
  "priority": 100,
  "enabled": true,
  "minLoaderVersion": "0.6.0-beta",
  "supportedGameVersions": ["*"],
  "dependencies": [],
  "optionalDependencies": [],
  "incompatibleWith": [],
  "loadAfter": [],
  "loadBefore": []
}

Required

modName, authors, description, and priority.

Compatibility

minLoaderVersion, maxLoaderVersion, and supportedGameVersions.

Load rules

dependencies, optionalDependencies, loadAfter, and loadBefore.

Reports

Mod metadata results appear in mod status logs.
