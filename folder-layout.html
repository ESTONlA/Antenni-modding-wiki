Mod Basics

A clean folder layout prevents most install mistakes.

LOCLM mods should be installed as their own folder inside loclm/mods/. The DLL, manifest, assets, and dependency DLLs belong together.

Installed mod layout

loclm/mods
loclm/
\-- mods/
    \-- MyCoolMod/
        +-- MyCoolMod.dll
        +-- MyCoolMod.deps.json
        +-- modinfo.json
        +-- assets/
        |   +-- code/
        |   +-- data/
        |   +-- included/
        |   +-- sounds/
        |   \-- sprites/
        +-- UndertaleModLib.dll
        \-- Underanalyzer.dll

Folder rules

Do not put loose DLLs directly in mods/.Keep the folder name and main DLL name matched.Keep metadata beside the DLL.Keep GML assets under assets/code/.Keep user config under assets/data/.Do not edit the original game data.win.

Common mistakes

  • Uploading bin/Release instead of the configured output folder.
  • Nested folders such as MyCoolMod/MyCoolMod/MyCoolMod.dll.
  • Missing modinfo.json because it was left in IncludedFiles/.
  • Missing assets because the project file was renamed without preserving the copy targets.
