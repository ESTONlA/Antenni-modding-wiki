Recipe

Recipe: ship a data file and reference it from GML.

Use assets/included/ for files that your mod needs at runtime. The file stays beside the mod and is not injected into data.win.

Step 1: add the file

Source
assets/
\-- included/
    \-- my_data.json

Step 2: get the game path

C#
string gmlPath = context.GetIncludedFileGamePath("included/my_data.json");

The helper returns a relative path like loclm/mods/MyCoolMod/assets/included/my_data.json.

Step 3: inject the path into GML

GML asset
var path = "__DATA_PATH__";
if (file_exists(path)) {
    var text = file_text_open_read(path);
}
C#
context.AppendCodeFromFile(
    "hooks/read_data.gml",
    "gml_Object_obj_example_Create_0",
    ("__DATA_PATH__", QuoteGmlString(gmlPath)));

Rules

Do not use absolute PC paths.Keep files under assets/included/.Use token replacement for paths.Ship the whole output folder.Handle missing files in GML if optional.Use RequireIncludedFile if required.
