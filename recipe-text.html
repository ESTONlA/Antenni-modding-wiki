Recipe

Recipe: replace one piece of game text without wrecking everything.

Text changes should be exact and counted. If the loader finds zero matches or too many matches, the mod should fail instead of patching random text.

Exact string replacement

Use this when you know the full text.

C#
context.ReplaceGameString(
    "Original Text",
    "Replacement Text",
    expectedMatches: 1);

Contained text replacement

Use this only when the full string has dynamic content or formatting that makes exact matching painful.

C#
context.ReplaceGameStringContains(
    "Original",
    "Replacement",
    expectedMatches: 1);
Do not search for tiny words.

Searching for the, new, or yes can match many strings. Use the most unique text you can.

Patch text inside a generated GML file

For GML templates, use tokens. This avoids hardcoding config values inside the GML asset.

GML
draw_text(x, y, __MY_LABEL__);
C#
context.AppendCodeFromFile(
    "hooks/my_draw.gml",
    "gml_Object_obj_example_Draw_0",
    ("__MY_LABEL__", QuoteGmlString("Hello")));

Test plan

  1. Run the mod alone.Confirm the expected text changed.
  2. Search logs for replacement count.The helper logs successful replacement counts.
  3. Try a wrong search string once.Make sure the mod fails clearly when the expected string is missing.
  4. Restore the correct search string.Never ship intentionally loose text replacement.
