Recipe

Recipe: create a GameMaker object and place it into a room.

This is useful for controller objects, debug overlays, runtime helpers, or hidden systems that need their own events.

Step 1: create the object

C#
UndertaleGameObject controller = context.CreateObject(
    "obj_my_mod_controller",
    visible: false,
    persistent: false);

NewObject is an alias for CreateObject.

Step 2: add event code

Create a GML file under assets/code/, then attach it to the object event.

GML file
assets/code/objects/obj_my_mod_controller_Create_0.gml
C#
context.CreateObjectCodeFromFile(
    "objects/obj_my_mod_controller_Create_0.gml",
    "obj_my_mod_controller",
    EventType.Create);

Step 3: place it in a room

C#
context.PlaceObjectInRoom(
    "rm_main_menu",
    controller,
    "Instances");
The room and layer must exist.

If the layer name is wrong or the layer does not accept object instances, the helper throws.

When to use this

Runtime logging controller.Hidden menu state manager.Debug overlay.Mod initialization object.Custom interaction object.Room-specific feature object.

Common mistakes

  • Creating an object name that already exists.
  • Placing the object into a room layer that does not accept instances.
  • Forgetting to attach event code.
  • Making a controller visible when it should be hidden.
