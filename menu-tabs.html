Patching

Use CreatureProbe as the menu-tab example.

The template adds a main-menu button and opens a custom tab. Treat it as a small working pattern, not as the only possible UI system.

What the sample patches

TargetWhy
gml_GlobalScript_main_menu_spawn_buttonsUnlocks or creates the button slot.
gml_Object_obj_button_menu_Alarm_0Sets menu button text.
gml_Object_obj_button_menu_Alarm_2Maps button click behavior.
gml_Object_obj_ctrl_main_menu_Draw_0Draws the custom tab text.
gml_Object_obj_ctrl_main_menu_Step_0Handles tab state and input.
gml_Object_obj_ctrl_main_menu_Alarm_2Handles delayed menu button behavior.

Pick safe indexes

The template defaults to button index 68 and back button index 69. Change these if another mod uses them.

Indexes are a conflict point.

If two mods claim the same button index or menu ID, one can overwrite the other. Document your indexes in your mod README.

Keep menu text configurable

mod-config.json
{
  "enableMenuTab": true,
  "mainMenuButtonIndex": 68,
  "backButtonIndex": 69
}

The label, title, body, and back label can also be defined in ModConfig.cs defaults or added to JSON.

Polish checklist

Use the game's existing font and draw style.Use a back button that matches other menu buttons.Do not open your tab from every button click.Reset menu state when leaving the tab.Test with a controller if the game supports it.Test with another menu mod enabled.
