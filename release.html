Building & Release

Ship a complete mod folder, not a loose DLL.

Most broken installs happen because the release zip is missing metadata, assets, config files, or dependency DLLs.

Player install target

Release folder
loclm/mods/MyCoolMod/
+-- MyCoolMod.dll
+-- MyCoolMod.deps.json
+-- modinfo.json
+-- assets/
+-- UndertaleModLib.dll
\-- Underanalyzer.dll
Do not ship only MyCoolMod.dll.

Config files, GML assets, metadata, and dependencies are part of the mod.

Release checklist

Main DLL matches folder name.modinfo.json is present and valid.Assets/config files are copied to output.Dependency DLLs are included.Debug symbols are removed unless needed.Mod was tested alone.Known conflicts are documented.Install instructions mention copying the whole folder.

Common mistakes

  • Uploading the build DLL without the output folder.
  • Leaving template author/name values in modinfo.json.
  • Forgetting assets/data/mod-config.json.
  • Testing only in a dirty mods folder with other mods enabled.
