Release checklist

Ship a complete mod folder, not a loose DLL.

Most broken installs happen because the release zip is missing metadata, assets, config files, or dependency DLLs.

Player install target

Players copy your full folder into loclm/mods/.

loclm/mods/MyCoolMod/
+-- MyCoolMod.dll
+-- MyCoolMod.deps.json
+-- modinfo.json
+-- assets/
+-- UndertaleModLib.dll
\-- Underanalyzer.dll
Main DLL matches folder name. modinfo.json is present and valid. Assets/config files are copied to output. Dependency DLLs are included. Debug symbols are removed unless you want them public. Mod was tested alone. Mod was tested with common other mods if possible. Known conflicts are documented.
