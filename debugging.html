Debugging

Use the loader reports before guessing.

LOCLM writes mod status, failed mod, security, and conflict reports to help you find broken patches quickly.

Main log

LOCLM.log

Use this for loader flow, warnings, mod load order, and patch failures.

Summary

LOCLM_summary.txt

Use this when a tester sends you logs. It includes version, paths, hashes, warnings, and errors.

FileUse
mod_status.jsonFull per-mod compatibility, load, security, and resource report.
failed_mods.jsonMods that failed metadata, dependency, or runtime loading.
security_report.jsonHash and scan result if the mod was blocked.
mod_conflicts.jsonResources touched by more than one mod.
LOCLM_runtime.logRuntime messages written by in-game hooks.

Workflow

Debug in the smallest possible setup.

Test your mod alone. Delete stale cache only if you suspect old output. Check that your find/replace search string still exists. Check generated conflict report. Check button indexes and menu IDs. Ask testers for the whole loclm/Logs/ folder.
