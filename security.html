Security scan

Basic protection before a mod DLL loads.

LOCLM checks mod DLLs for suspicious behavior and blocks risky mods before loading them.

False positives can happen

A warning can be false, but it is not always false. Do not allowlist a mod just because you want it to load.

Reports

Security results are written to loclm/Logs/security_report.json and blocked_mods.json.

Allowlist format

Only add hashes for mods you trust.

{
  "allowedModHashes": [
    "PUT_TRUSTED_MOD_SHA256_HASH_HERE"
  ]
}
Need help?

Send security_report.json to the mod author.
