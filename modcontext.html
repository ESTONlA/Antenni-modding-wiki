ModContext

The template helper for common mod tasks.

ModContext wraps asset loading, logging, JSON config, code patching, and resource lookup so your mod code stays readable.

Basic setup

Create the context after LOCLM calls your Load method.

ModContext context = ModContext.Create(data);
ModConfig config = context.LoadJson<ModConfig>("data/mod-config.json", required: false)
    ?? new ModConfig();

context.Log("Loaded config.");
