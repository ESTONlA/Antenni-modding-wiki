Getting Started

The Load method is your mod entry point.

LOCLM loads the mod DLL, finds a public Load method, and gives it the audiogroup number plus the current UndertaleData.

Template pattern

C#
public void Load(int audiogroup, UndertaleData data)
{
    if (audiogroup != 0)
    {
        return;
    }

    ModContext context = ModContext.Create(data);
    ModConfig config = context.LoadJson<ModConfig>("data/mod-config.json", required: false)
        ?? new ModConfig();

    InstallMainMenuTab(context, config);
}

Why audiogroup 0 matters

The main game data is patched when audiogroup is 0. The template returns early for other audiogroups so it does not accidentally patch the wrong data pass.

Keep the guard unless you know why you are removing it.

Most mods should patch only the main data pass. Removing the guard can create duplicate patches or strange resource behavior.

Split your code

Keep Load readable. Use small helper methods for each feature.

C#
InstallMainMenuTab(context, config);
InstallNewStrings(context);
InstallSprites(context);
InstallSoundReplacements(context);

This makes it obvious which feature caused a failure when the loader logs stop at a specific step.

Common mistakes

  • Renaming the class but not the namespace or project output.
  • Throwing away the audiogroup guard while still using the template patch style.
  • Doing everything inside Load until it becomes impossible to debug.
  • Calling ModContext.Create before validating the data pass.
